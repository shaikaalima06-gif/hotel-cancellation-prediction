\# Preprocessing Workflow



\## Objective

Prepare the hotel booking dataset for machine learning.



\## Preprocessing Steps

1\. Load the hotel booking dataset.

2\. Handle missing values.

3\. Remove data leakage columns.

4\. Separate features and target.

5\. Split data into training and testing sets.

6\. Apply numerical scaling.

7\. Apply categorical encoding.

8\. Save the processed datasets.



\## Result

The dataset is prepared for model training and evaluation.
