\# Developer 2 - Validation Workflow



\## Responsibility

Develop and maintain the data validation and model evaluation checks.



\## Validation Activities

\- Check required dataset columns.

\- Identify missing values.

\- Verify target column availability.

\- Check training and testing feature consistency.

\- Validate preprocessing outputs.

\- Review model evaluation metrics.



\## Validation Process

1\. Load the hotel booking dataset.

2\. Check the dataset structure and required columns.

3\. Identify missing and invalid values.

4\. Verify preprocessing output files.

5\. Check consistency between training and testing features.

6\. Review model evaluation results.



\## Result

The validation workflow is maintained independently in the validation branch.
