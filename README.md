\# Hotel Booking Cancellation Prediction



\## Project Objective



This project predicts whether a hotel booking will be cancelled using machine learning.



\## Dataset



The project uses the Hotel Booking dataset.



Target variable:

\- `is\_canceled`



Where:

\- 0 = Not Cancelled

\- 1 = Cancelled



\## Machine Learning Models



The baseline models implemented are:



1\. Logistic Regression

2\. Decision Tree

3\. Random Forest



\## Current Results



Random Forest:



\- Accuracy: 0.8486

\- Precision: 0.7745

\- Recall: 0.6339

\- F1 Score: 0.6972

\- ROC-AUC: 0.9068
